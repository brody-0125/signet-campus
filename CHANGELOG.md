# Changelog

## 1.1.0 — 2026-09-14

- React workspace for evidence review, feedback, resubmission and recent learner submissions.
- Draft/publication, archival/restoration and successor editions with immutable historical criteria.
- Learning pathway prerequisites, enrollment, current-credential progress and signed completion awards.
- Persistent Open Badges issuance, verification, revocation, key rotation, JSON/PNG/SVG export and private-by-default sharing.
- Personal registration with email verification, account management and institutional account continuity.
- Transactional enrollment email delivery with retry and worker crash recovery.
- HTTPS, proxy replacement, private telemetry, two-instance concurrency and application/identity recovery rehearsals.
- Published Signet starter v0.1.6 and Core v0.1.5, including extension contexts and exact Unicode preservation; independent schema and proof verification.
- Application and dependency notices in distributions, with the exact MPL-covered Public Suffix List source and corresponding-source references.

Existing signed credentials remain unchanged during upgrades. See [interoperability](docs/INTEROPERABILITY.md) for earlier Signet proof compatibility and [account configuration](docs/ACCOUNT.md) for persistent realm updates. The earlier v1.0.0 tag remains the original development baseline.

## 1.0.0 — 2026-09-14

- Kotlin and Spring Boot integration with the published Signet starter.
- Credential signing and verification contract tests.
- Dependency inventory with artifact hashes and license notices.
- MIT license and third-party attribution.
