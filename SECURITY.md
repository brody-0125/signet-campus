# Security

This is an early development project; version 1.0.0 is not a production security assurance. Do not process real learner data with the current baseline.

Report vulnerabilities privately using GitHub's **Report a vulnerability** action in this repository's Security tab. Do not put private keys, personal data or exploit details in a public issue. Include the affected commit, reproduction with synthetic data, expected/actual behavior and impact.

Only the current development line receives fixes at this stage. No response SLA or long-term maintenance window is promised.
